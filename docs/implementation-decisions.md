# 本次实现决定与代价

1. **隔离工作**：新建独立英文目录和干净 Git 历史，不修改用户原项目和板厂例程。代价是新仓库不保留上游完整提交历史；用来源、参考提交和许可声明追溯。
2. **Windows 执行**：把技能里的类 Unix 辅助命令换为 Windows 原生操作及执行账本。核验依赖真实构建、下载和行为测试，不把脚本名称当作证据。
3. **QoS0 兼容性**：缓存仅在 ESP8266 的 SEND OK 后消费，保留原链路的 QoS0。它不证明云端持久化，发送不确定时可能重复；需要更强保证时需另行实现 broker ACK/业务确认和去重。
4. **存储自检**：在原分配的4MB日志区域首部留4KB自检扇区，日志从0x01801000开始。代价是日志容量减少4KB；若该扇区有未知数据则跳过自检而不擦除。本次实测PASS。
5. **显示一致性**：SDRAM帧缓冲不可缓存；LVGL直接输出原生RGB565，不延续原SPI小屏的字节交换。代价是暂未做DMA2D/cache性能优化，当前以正确显示为先。
6. **内核端口**：使用已移入的ARMCC通用FPU端口，CPUID实测为M7r1p1，任务调度已运行；并非未经核对把不支持的早期M7版本强行启用。
7. **Flash故障降级**：只有未成功持久化的真实样本进入有界内存发送路径。代价是断电或长时间积压会丢失部分降级样本，不能把它描述为持久缓存。
8. **发布内容**：源码仓库排除个人配置、编译产物和上游历史凭据；本地单独保留固件包。真实凭据配置进固件后，重新公开该固件也会泄露，需自行保持私密。
9. **第三方版权**：保留ST、Arm、FreeRTOS、LVGL和ALIENTEK原声明，不将板厂BSP统一改成MIT。商用/再次分发必须核对对应授权。
10. **证据边界**：烧录校验、SWD诊断、RAM帧缓冲与主机测试已完成；用户实物触摸、面板观感和缺失外设链路不由这些证据替代。代价是这些项目仍需人工/外设到齐后验收。

独立审查的四项重要问题已通过先失败后通过的回归测试修复；没有列为“已知但不修复”的轻微审查项。上游LVGL的23个编译警告保留并在验证记录中说明。
